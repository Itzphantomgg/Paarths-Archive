# Project Skills & Capabilities: Paarth's Archive

## 1. Project Purpose
"Paarth's Archive" is a private-feeling digital memory vault, storytelling platform, and personal autobiography website. It is designed with a monochrome cinematic aesthetic, editorial luxury feel, high-contrast serif typography, and contemplative film-first pacing inspired by vintage editorial and film photography.

## 2. Technology Stack
- **Framework**: Next.js 14/16 (App Router, Turbopack)
- **Language**: TypeScript (Strict mode enabled)
- **Styling**: Tailwind CSS with `@tailwindcss/typography`, custom animations, and procedural 35mm film grain
- **Database Layer**: Prisma ORM with SQLite (zero-config local relational DB + Vercel `/tmp` persistence) and PostgreSQL mirror schema (`supabase/schema.sql`)
- **Authentication**: Custom session-based auth with `bcryptjs` password hashing, `jose` signed JWT httpOnly cookies (`archive_session`), and route protection in `src/middleware.ts`
- **Icons**: Lucide React
- **Audio**: Web Audio API synthesizer for optional analog tape hiss / vinyl warmth without external audio assets

## 4. Authentication Architecture
- Passwords hashed using `bcryptjs` with salt rounds = 10.
- Sessions signed via `jose` with HS256 HMAC tokens stored in httpOnly `archive_session` cookie (30-day expiration, `sameSite: "lax"`).
- Route middleware (`src/middleware.ts`) protects all `/admin/*` routes. Unauthenticated requests are redirected to `/login?redirect=<path>`.
- Client-side navigation updates dynamically based on `/api/auth/me`.

## 5. Database Architecture
- Relational schema defined in `prisma/schema.prisma`.
- Models:
  - `User`: Archivist credentials, role, metadata.
  - `Chapter`: Sequential volumes (`01 CHILDHOOD`, `02 GROWING UP`, etc.).
  - `Story`: Rich narrative entries with status (`DRAFT` vs `PUBLISHED`), approximate dates, locations, mood, people involved, and Markdown text.
  - `Tag` & `StoryTag`: Many-to-many relationship for index categorization.
- For local dev: reads from `prisma/dev.db`.
- For Vercel Serverless: `src/lib/db.ts` automatically copies the bundled seed DB to `/tmp/archive.db` if `DATABASE_URL` is not pointing to an external PostgreSQL instance, preventing read-only filesystem errors (`EROFS`).

## 6. Rules for Future Modifications
1. **Never commit passwords or real secrets**: Keep `.env` and `.env.local` ignored.
2. **Never display dummy passwords in UI or documentation**: Authentication forms should have standard placeholders without pre-filled secrets.
3. **Preserve the visual aesthetic**: Maintain deep black backgrounds (`#050505`), thin 1px borders (`border-white/10`), high-contrast editorial serif headlines, and generous whitespace.
4. **Preserve Next.js App Router conventions**: Unpack dynamic parameters asynchronously (`await params`, `await searchParams`, `await cookies()`).
5. **Always verify with production build**: Run `npm run build` to ensure type safety and route compilation.
